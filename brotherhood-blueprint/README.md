```bash

- index.html       → Update host names, photos, links
- about.html       → Customize vision and values

- platforms.html   → Link podcast platforms
```

### 2. Add Photos (6 required)
- Group photo (1200x600px)
- 3 host headshots (400x350px each)
- 2 cinematic moments (1200x400px each)

### 3. Link Your Socials
- YouTube, TikTok, Facebook, Instagram
- Spotify & Apple Podcasts

### 4. Deploy
Choose any hosting: GitHub Pages, Netlify, Vercel, or your own server

## 🎨 Design System

### Color Palette
```
Primary Background:    #0f172a  (Deep Navy)
Accent (Blueprint):    #2f5d95  (Premium Blue)
Primary Text:          #f1f5f9  (Soft White)
Secondary Text:        #94a3b8  (Muted Gray)
```

### Typography
- **Headlines**: Bold, scaled from 60px to 20px
- **Body**: 16px base, 1.8 line height for readability

```

```

## 🌐 Deployment Options

### GitHub Pages (Free)
1. Create GitHub repo
2. Upload files
3. Settings → Pages → enable
4. Live at `username.github.io`

### Netlify (Free)
1. Go to netlify.com
2. Drag & drop folder
3. Live in seconds
4. Custom domain available

### Vercel (Free)
1. Connect GitHub repo
2. Auto-deploys on push
3. Fast global CDN

### Traditional Hosting
Upload via FTP or hosting control panel
